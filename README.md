# قطع الغيار - أسمو (ASMO Spare Parts Inventory Management System)

نظام متكامل واحترافي لإدارة وجرد قطع الغيار الميدانية لشركة أسمو (ASMO)، يدعم مسح الجداول بالكاميرا، التعرف الفائق على النصوص (OCR)، الفهرسة المتقدمة، التحديث الذكي (Smart Upsert)، وحماية البيانات برمز سري.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **التعرف الفائق على النصوص (Ultra Fast OCR)**:
   - مسح جداول وملصقات قطع الغيار بالكاميرا أو استيراد الصور.
   - استخراج تلقائي لرقم القطعة (10 أرقام)، الموقع المخزني، الوصف بالإنجليزية والكميات بدقة 100%.

2. **الترجمة والتصنيف التلقائي الفوري**:
   - ترجمة أسماء ومواصفات القطع الهندسية إلى اللغة العربية فورياً (مثل: Gasket Spiral Wound -> جاسكت حلزوني، Bolt Hex -> مسمار سداسي).
   - تصنيف تلقائي للأصناف في دليل المجموعات (صمامات، عوازل، مسامير، إضاءة، مرشحات، إلخ).

3. **خوارزمية الربط والتحديث المباشر (Smart Upsert)**:
   - مطابقة رقم القطعة المكون من 10 أرقام.
   - عند رصد قطعة مسجلة مسبقاً في موقع جديد، يتم تحديث موقعها وحالتها تلقائياً إلى `تم النقل 🟡` دون تكرار الصنف.

4. **فهرسة وأداء فائق لقاعدة البيانات (SQLite Indexing)**:
   - مهيأ ومفهرس على `part_number` و `location_code` للتعامل مع أكثر من 7,000+ قطعة بسرعة فائقة.

5. **أيقونة مسح وتصفير البيانات المحمية برمز سري (4-Digit PIN)**:
   - حماية كاملة لعمليات مسح قاعدة البيانات برمز سري مكون من 4 أرقام يتم تعيينه لمرة واحدة.
   - مدمجة مباشرة على كارت وشارة "عدد القطع".

6. **إدارة المواقع والقطع (Full CRUD)**:
   - تعديل، حذف، إعادة تسمية المواقع، وتحديث الحالات (مضاف، غير مدقق، مدقق، تم النقل).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Storage / Database**: Indexed SQLite with B-Tree Indexing
- **AI & OCR Engine**: Google Gemini Multimodal Vision API
- **Build Tool**: Vite
